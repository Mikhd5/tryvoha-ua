# ТРИВОГА.UA — стартовий MVP
Next.js + TypeScript. Український адаптивний UI-прототип із екранами Головна, Radar, AI News, Family Link та Help & Community.

## Локальний запуск
Потрібен Node.js 20+.
```bash
npm install
npm run dev
```
Відкрити http://localhost:3000

## Важливо
Це UI-прототип. Дані, міста й статуси демонстраційні. Немає підключення до офіційних джерел, Supabase, Telegram або реальних сповіщень. Не використовувати для рішень щодо безпеки.

## Наступні кроки
1. Завантажити код у приватний GitHub-репозиторій.
2. Підключити Supabase Auth, PostgreSQL і Row Level Security.
3. Реалізувати backend для профілів, міст, підписок і джерел.
4. Підключити перевірені офіційні джерела з моніторингом актуальності.
5. Додати Telegram Bot / Mini App.
6. Провести аудит безпеки, приватності й надійності перед публічним запуском.

Критичні сповіщення не повинні залежати від AI. AI може лише узагальнювати й перекладати інформацію з першоджерел. Не збирати геолокацію без чіткої потреби та згоди.
