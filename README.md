# ТРИВОГА.UA — стартовий MVP

Next.js + TypeScript. Український адаптивний UI-прототип із екранами Головна, Радар, Новини, Родина та Спільнота.

## Локальний запуск
Потрібен Node.js 20+.
```bash
npm install
npm run dev
```
Відкрити http://localhost:3000

## Важливо
Це UI-прототип. Дані, міста й статуси демонстраційні. Немає підключення до офіційних джерел, Supabase, Telegram або реальних сповіщень. Не використовувати для рішень щодо безпеки.

Критичні сповіщення не повинні залежати від AI. AI може лише узагальнювати й перекладати інформацію з першоджерел. Не збирати геолокацію без чіткої потреби та згоди.

## Наступні кроки
1. Підключити Supabase Auth, PostgreSQL і Row Level Security.
2. Реалізувати backend для профілів, міст, підписок і джерел.
3. Підключити перевірені офіційні джерела з моніторингом актуальності.
4. Додати Telegram Bot / Mini App.
5. Провести аудит безпеки, приватності й надійності перед публічним запуском.
