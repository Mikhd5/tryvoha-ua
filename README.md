# ТРИВОГА.UA

Український цифровий простір із радаром обраних міст, перевіреними повідомленнями, новинами з першоджерелами та добровільним сімейним check-in.

## Локальний запуск

Потрібен Node.js 20+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Відкрити http://localhost:3000.

## Supabase

1. Створи Supabase project.
2. Скопіюй Project URL та anon/publishable key у `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. Застосуй міграції через Supabase CLI: `supabase db push`.
4. Додай ті самі дві змінні у Vercel для Development, Preview та Production.
5. Перезапусти deployment.

Міграція створює профілі, міста, підписки, таблиці подій/новин і сімейні групи з RLS. Вона не наповнює базу вигаданими активними тривогами та не вмикає інжест.

## API

- `GET /api/health` — перевірка застосунку та наявності конфігурації Supabase.
- `GET /api/alerts` — тільки опубліковані події з бази; за відсутності конфігурації повертає 503.
- `GET /api/news` — тільки опубліковані новини з бази; за відсутності конфігурації повертає 503.

## Безпека та межі

- Поточний UI містить демонстраційні дані й не є офіційною системою оповіщення.
- Не використовувати цей сайт як заміну офіційним каналам та інструкціям служб.
- Критичні сповіщення не повинні залежати від AI.
- AI може узагальнювати/перекладати тільки після отримання перевіреного першоджерела; джерело та час мають бути видимими.
- Координати військових об'єктів, переміщень і чутливі оперативні дані не збирати та не публікувати.
- Геолокація не збирається; Family Link побудований на добровільному check-in.
- Секретний service-role key не можна додавати до `NEXT_PUBLIC_*` змінних або клієнтського коду.

## Що ще не підключено

Реальна авторизація в інтерфейсі, адаптери офіційних джерел, перевірка/модерація публікацій, push/Telegram-сповіщення, AI-пайплайн, сімейні запрошення та аудит безпеки. Не вважати продукт production-ready до їх реалізації та тестування.
